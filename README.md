1. Dans quel dossier doit se trouver un workflow ?
.github/workflows/
2. Quel est le format du fichier ?
YAML (.yml ou .yaml)
3. Quels sont les trois éléments minimum d'un workflow ?
Un déclencheur (on), un job (jobs) et une commande exécutée dans un step (run).
4. Comment déclencher un workflow à chaque push ?
Avec : on: push
